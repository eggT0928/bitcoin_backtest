# 事前 분석 수정 이력

## A1 — 데이터 접근 제약, 성과 계산 전 (2026-09-16 UTC)

Yahoo Finance가 실행 환경의 기관 네트워크에서 403으로 차단됨. Coin Metrics Community API도 접근 불가.
접근 가능한 공식 [Coin Metrics 공개 아카이브](https://github.com/coinmetrics/data)에서 PriceUSD를 사용한다.
[공급자 정의](https://gitbook-docs.coinmetrics.io/network-data/network-data-overview/market/price)에 따르면 1d PriceUSD는 해당 UTC 일말 가격이다.
날짜를 이동하거나 다른 공급자와 이어 붙이지 않는다. 논문/전략 규칙과 시작일은 그대로 둔다.
최초 데이터 검토 시 아카이브의 유효 마지막 가격은 **2026-05-23**. 마지막 2026-05-24 행의 PriceUSD는 비어 있어 제외한다.
실제 주 분석 범위는 2014-09-17부터 추출, 성과는 2015-08-02부터. 2009–2014 초기 데이터를 추가하지 않는다.
이 결정까지 BTC 전략 성과를 한 번도 계산하거나 열람하지 않았다. 공급자 변경은 성과 선택이 아닌 접근성 제약 때문이다.
대시보드는 고정 스냅샷을 기본으로 하고, 데이터 마지막 날과 자료 노후화를 명시한다. 최신 시세로 오인할 '현재' 표기를 피한다.
향후 Yahoo 연결이 복구되면 공급자를 명시해 전 전략을 한 번에 재계산할 수 있으나 이번 결론과 섞지 않는다.

## A2 — pandas 호환성, 성과 계산 전

원본 state_signal의 shift/fillna 후 반전이 pandas 3에서 object bool 반전 경고를 발생시킨다.
`.astype(bool)`을 명시했다. 연속 조건을 만족한 첫날만 이벤트가 된다는 기존 정의를 고정 테스트로 확인했다.
모의 데이터의 100% 비중 비교는 부동소수점 허용오차 1e-12를 사용한다. 전략 규칙 변경 없음.
